The repository describes the content as colour images of oral lesions captured with mobile cameras and intra-oral cameras, collected in consultation with doctors from hospitals and colleges in Karnataka, India. It has two folders: `original_data` (165 benign, 158 malignant) and `augmented_data` (flipped, rotated and resized copies).

## What we use
- **Only `original_data`.** The augmented folder is excluded from all model training and evaluation, because its files are transformed copies of the originals (see *Leakage audit* below).
- **Classes:** `benign` (label 0) and `malignant` (label 1), taken from the folder names. The repository does not say whether labels are histopathology-confirmed.

| Rule | Check | Result |

| — | Missing labels (files outside a class folder) | 0 files |
| — | Manual relabelling | **none** — there is no reference standard to verify labels against |

**No image was deleted.** All 323 originals remain in the study.

### Near-duplicate detection
1. **Perceptual hash, invariant to 8 flips/rotations, threshold 6/64 bits.** It found 0 pairs, but it missed obvious re-crops of the same photograph. For example, `malignant/125` and `malignant/91` differ by 8 bits.
2. **ImageNet ResNet-50 embeddings (cosine similarity).** Pairs at ≥0.91 were re-crops of one photograph. Pairs between 0.845 and 0.88 showed the same patient or lesion from a slightly different view; we reviewed 18 pairs in a contact sheet.

**Threshold sweep:**

| Threshold | Multi-image groups | Images in groups | Largest group | Mixed-label groups |
|---|---|---|---|---|
| 0.90 | 7 | 14 | 2 | 0 |
| **0.84 (chosen)** | **14** | **30** | **3** | **0** |
| 0.83 | 14 | 37 | 9 | 1 |
| 0.80 | 20 | 92 | 36 | 2 |

We chose 0.84 because it captures all visually confirmed same-patient pairs before chaining starts. Groups never cross the test/development boundary or fold boundaries; this is asserted in code.

## Preprocessing
1. Apply EXIF orientation.
2. Convert to RGB.
3. Resize to 256 × 256 (Lanczos). Aspect ratio is not preserved, which avoids padding borders whose shape could encode the original aspect ratio.
4. Save as PNG. EXIF and all other metadata are stripped; 0/323 cleaned files contain EXIF.

At training/inference time:
- **Evaluation:** resize to 224 × 224 and normalise with ImageNet mean/std.
- **Training only:** random resized crop (scale 0.7–1.0), horizontal/vertical flips, rotation ±20° and mild colour jitter, applied on the fly.

## Leakage audit of the repository's `augmented_data` folder
Script: `src/duplicate_and_leakage_audit.py`. Results: `results/tables/leakage_audit_summary.csv`.
- **Sample:** 2,000 augmented files (the first 1,000 per class returned by the Mendeley API, which lists at most 1,000 files per folder).
- **Matching:** each augmented file was matched to its most similar original, using the maximum cosine similarity over 16 rotation/mirror variants of every original.

**Findings**
- 98.7% of augmented files match an original with the same label.
- 322 of 323 originals have at least one augmented file more similar to them than 99% of unrelated-original pairs (threshold 0.857).
- In a visual check of 40 random pairs, 39 were clearly the same source photograph and 1 was uncertain (`leakage_audit_visual_sample.csv`).

**Conclusion:** the augmented folder consists of transformed copies of the 323 originals. Any protocol that trains on it and tests on the originals evaluates on images whose copies were seen in training.

## Known limitations
- **Small** (323 images): wide confidence intervals are unavoidable.
- **No patient identifiers.** At least 14 groups of images show the same lesion or patient. Grouping reduces, but cannot rule out, residual same-patient overlap between splits.
- **Label provenance.** Labels come from folder names. Histopathological confirmation, lesion subtypes and the timing of diagnosis are not documented.
- **Acquisition bias.**
  - Malignant images are smaller (median 0.18 MP vs 0.40 MP).
  - Camera models differ by class: Samsung SM-M315F appears in 35 benign and 0 malignant files; SM-G360H in 12 malignant and 2 benign.
  - A logistic regression on file metadata alone (width, height, size, EXIF presence, JPEG quantisation) separates the classes with cross-validated AUC 0.776 (`results/tables/metadata_shortcut.csv`).
  - Models trained on these pixels could partly learn acquisition differences instead of lesion appearance. This is tested in Weeks 5–6.
- **Single region** (Karnataka, India). Skin tone, habits (e.g. tobacco/areca use) and lesion spectrum may not generalise.
- **Heterogeneous framing.** Some images show the whole mouth with teeth, lips or facial hair; others are close-ups. Lesions are not annotated (no masks or boxes).
- **Binary labels only.** OPMD and lesion-type information is not available.

## Ethical considerations
- **Licence:** CC BY 4.0 permits reuse with attribution. The dataset is cited in all outputs.
- **Consent:** the repository does not document ethics approval or patient consent. We use the data only as published, for non-commercial academic research. We do not attempt re-identification and do not link the images to any other data.
- **Privacy:**
  - 15 raw files contain an empty GPS EXIF block (no coordinates); 306 contain capture timestamps; device make/model is present in some files.
  - All EXIF is removed from the processed copies used for modelling and figures.
  - Figures use cropped intra-oral views only. A few raw images include lips or facial hair, but no full faces.
- **Intended use:** method development and teaching on image classification and explainability. **Not** for clinical diagnosis, triage or any decision about a patient. The model has not been clinically validated.
- **Fairness:** patient demographics (age, sex, ethnicity) are not provided, so subgroup performance cannot be assessed. This is reported as a limitation.

## Data dictionary

### `data/splits.csv` — one row per image (323 rows)

| Column | Type | Description |
|---|---|---|
| `file` | str | Path of the raw image relative to `data/raw/original_data/` (e.g. `benign/12.jpg`) |
| `clean_file` | str | Path of the preprocessed 256×256 PNG relative to `data/cleaned/` |
| `class` | str | `benign` or `malignant` (repository folder name) |
| `label` | int | 0 = benign, 1 = malignant (positive class) |
| `dup_group` | int | Near-duplicate group id (connected component at cosine ≥ 0.84); singletons have their own id |
| `group_size` | int | Number of images in the group |
| `split` | str | `dev` (258) or `test` (65) |
| `fold` | int | Cross-validation fold 0–4 for development images; −1 for test |
| `canonical_split` | str | `train` (dev folds 1–4), `validation` (dev fold 0) or `test`; mirrors the `data/{train,validation,test}/` folders |
| `width`, `height` | int | Original pixel dimensions |
| `bytes` | int | Original file size |
| `has_exif` | bool | Whether the original file carried EXIF metadata |
| `sha256` | str | SHA-256 of the original file |
